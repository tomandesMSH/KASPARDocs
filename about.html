Why Kaspar exists, how the scripts work and who maintains them.

Why I made Kaspar

Windows has always had its quirks, but at some point it crossed a line. Ads in the Start menu. Bing opening when you just wanted to launch an app, and a right-click menu that hides half its options behind an extra click. These aren't obscure, forgotten settings, they're everyday features. Requiring an internet connection just to install the OS is a good example of decisions that don't benefit the user. None of this was asked for, and Microsoft keeps pushing it anyway. Kaspar exists to give that control back.

Meet Kaspar

Kaspar started as a personal collection: fixes written out of frustration, obscure registry tweaks only a handful of people remember. Over time, that collection of tweaks I knew by heart grew into something worth sharing, so I turned them into scripts anyone can run. Every script here solves a real problem that Microsoft either won't fix or keeps reintroducing.

How it works

Most of what Kaspar does comes down to the Windows Registry, a massive settings database that Windows reads constantly. The vast majority of tweaks applied here are settings that already exist inside Windows. Microsoft just doesn't give you a button for them. Kaspar does.

Scripts are written in Python using the winreg library. They are then compiled into standalone .exe files, so you don't need Python (or any of the dependencies) installed to run them. Every script is tested thoroughly, and almost all of them can revert their changes, so nothing is permanent.

Before running anything, use RestorePoint.py to create a system snapshot.

Kaspar Launcher

Running individual scripts works, but it gets tedious. Kaspar now comes with a launcher, a desktop app built with Electron that lets you pick scripts and run or revert them in one go. You can try a demo of it in your browser.
