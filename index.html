The official documentation for Kaspar

Kaspar is a collection of scripts that restore control over Windows, addressing the quirks, restrictions and inefficiencies Microsoft has introduced over the years.

Download Kaspar Read the docs Try the demo

What Kaspar fixes

Every script, grouped by what it changes. Each one links to its code and the registry keys it touches.

Privacy and ads

  • DisableAdvertisementID.pysafeStops Windows from using your ad ID and cuts telemetry
  • StartAds.pysafeRemoves sponsored app suggestions in Start
  • DisableDynamicSearch.pysafeRemoves news and highlights from Search
  • LocalSearch.pysafeKeeps Bing results out of Windows Search

Interface and shell

  • ClassicRClickMenu.pysafeRestores the full Windows 10 context menu
  • EndTask.pysafeAdds End Task to the taskbar right-click menu
  • DropFileRemove.pysafeDisables the drag-and-drop sharing pop-up
  • AskCopilotDisable.pysafeRemoves Ask Copilot from the context menu
  • DetailedShutdown.pysafeShows what Windows is doing while shutting down
  • ShutdownAndDontUpdate.pymoderateShut down without being forced to update

System and setup

  • RestorePoint.pysafeCreates a snapshot you can roll back to
  • PowerPlan.pysafeUnlocks hidden presets like Ultimate Performance
  • DeviceSetupRegion.pymoderateUnlocks features Windows blocks by region
  • LocalAccount.pymoderateCreates a local user or administrator account
  • LocalAccountDuringInstallationadvancedInstalls Windows without a Microsoft account
  • MicVolume.pysafeForces the microphone back to 100% and unmuted
  • ControlPanelGodMode.batsafeEvery Control Panel setting in one folder
  • rexplorer.batsafeRestarts Explorer so tweaks apply
